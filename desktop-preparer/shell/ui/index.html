Eliminar caché de CrossPoint

Se conservan tus libros, ajustes, progreso, estadísticas, palabras y partidas.

Qué caché eliminar

Se usa la última modificación del archivo. Esto libera espacio; no recupera versiones anteriores sobrescritas.
