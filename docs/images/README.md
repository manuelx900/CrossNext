Project presentation images supplied by the CrossNext maintainer for the repository README. Preserved as supplied; these are promotional compositions, not a hardware benchmark. Some embedded screenshots predate the final controls; the README records the differences.

`book-preparer.png` is the maintainer-supplied screenshot of CrossNext Book
Preparer 2.0.0. It is preserved without resizing or other image changes and shows
the initial English interface before a card is selected.

`pet.png` is the maintainer's PET overview, copied without modification from
`Diseño sin título.png`. It presents status, care, home and album. In the current
firmware, the food/remedies panel is informational and has no arrow or action.
