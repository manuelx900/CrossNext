# Citas, Notas, Fondos and carousel reference redesign

Citas reads the reader's `/My Clippings.txt`. It indexes the latest 512 complete records and groups them by book title and author. Imported record text is bounded to 4095 bytes, as the prior reader was; the firmware writer itself limits highlights to 2000 bytes. The list has All, Books and Favorites tabs, recent/oldest sorting, book-order sorting, separate favorite controls and paged quote detail. Preview truncation does not truncate the source quote.

Favorites and local removals are stored in `/.crosspoint/quotes.bin`; the pending file is validated before rotating the old primary to `.bak`. A checksum, bounded record count and version protect loading. Unreadable or future state disables mutations and reports the SD error. Removing a quote hides it in Citas and preserves the original clipping export. This avoids rewriting a file also owned by the reader and export/sync tools. Identity includes record bytes and original byte offset: appending preserves marks; externally reordering/replacing the clipping file can reset marks. Only entries still in the latest-512 catalog are retained on the next metadata write.

The quote activity owns fixed arrays, a 4 KiB record buffer and five row caches in its single nothrow activity allocation. There are no per-frame vectors, background tasks or bitmap caches. The S3 activity allocation is larger than the old offset-only list to support grouping and persistent flags; it is freed when the activity is destroyed. New metadata writes occur only for explicit favorite/remove actions. Storage access stays behind HalStorage/HalFile. The shared drawing helper allocates no heap memory.

Notas keeps Markdown files in `/notes` as the source of truth, preserves the Todo app and the live sleep-note renderer, and uses modification timestamps for recent sorting. Missing filesystem timestamps produce no invented updated date. The note reader paginates complete text and draws rules between paragraphs. Its options are Rename, Use while asleep, and Delete. Deletion and quote removal require a separate confirmation; repeating the original delete tap hits Keep rather than Delete.

Fondos lists supported image files in `/sleep`, `/WALLPAPER`, and `/wallpapers` on the local card. Hidden files, directories and cache files are excluded. Thumbnails always come from these files. The browser packager excludes the three wallpaper source directories from its default preload, so developer demo/reference images on disk cannot appear as built-in gallery choices. The QA page starts with an empty gallery and accepts only images selected through its file picker. No user image was deleted from disk.

The carousel cover moves down 28 logical pixels in portrait and 12 in landscape, with its caption group lowered 10 pixels overall. Its cover is slightly shorter, preserving at least eight pixels between the author and progress bar. A badge at the cover's upper right uses the same real saved progress as the bar and the framed layout.

## Verification and device handoff

Run the host `reading-tools`, `coherence`, `notes`, and `wallpapers` suites from the isolated QA runner. The browser preview is `site/qa-reading-tools.html`; its sample quotes/notes are disposable QA data. The normal simulator uses the actual native activities.

On both X4 Pro and Sticky, once a human builds/loads the accepted change: test portrait and landscape, open a long quote and long note, change tabs, sort and page, favorite/reopen, cancel removal by repeating the original tap, then confirm removal. Check that `/My Clippings.txt` is unchanged. Reenter the apps and verify persisted favorites and the sleep-note moon. Fill the SD card or disconnect it during a metadata write: an error should appear and the previous validated state should remain recoverable. A freeze, repeated SD error, missing text, overlapping controls or state loss is a failure. Check the carousel at 0%, a middle value and 100%, and verify the badge matches the bar. With no wallpaper files the gallery must be empty; add files to each supported folder and confirm only those appear. Remove a selected file and verify no built-in replacement appears.

Monitor serial free heap before entering and after leaving Citas repeatedly if testing the larger fixed activity on a device; it should recover after each activity destruction. Hardware timing, physical touch calibration, SD power-loss behavior and E-ink ghosting are not established by the browser or host tests.
