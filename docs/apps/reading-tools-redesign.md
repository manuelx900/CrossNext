# Citas, Notas, Fondos and carousel reference redesign

Citas reads the reader's `/My Clippings.txt`. It indexes the latest 512 complete records and groups them by book title and author. Imported record text is bounded to 4095 bytes, as the prior reader was; the firmware writer itself limits highlights to 2000 bytes. The All, Books and Favorites tabs appear above the result count. Populated quote lists also show an order control. Multi-page lists have page controls. A populated one-page Books list shows 1 / 1. Quote previews use compact cards with the excerpt above its source. In a book, the card shows the saved page. In the main lists, it shows the book title. The Books tab groups titles in compact rows styled like Collections, with an author and quote count for each book. Opening a book shows its title and author above the All and Favorites filters. Both filters keep the selected sort order and apply it within that book. Sort by date or by the order in the book. Open a quote to read the full saved text, see its source, and set its favorite status. The detail combines the book title, author, saved date and source page in one compact card above the passage. The opening and closing marks frame the first and last pages of the quote. The center pager appears for a long passage. The numbered quote arrows open adjacent quotes. The header gear in every list and in the quote detail opens Text Settings with the current font, size and alignment selected. The font picker includes the built-in quote faces and [fonts installed on the SD card](../sd-card-fonts.md). Quote typography affects the open passage. Each family offers its built-in sizes, installed bitmap sizes or the supported vector sizes up to 22 pt. The detail uses a smaller display face if the selected face is too tall for one complete line beside the quotation marks and pager. Save writes the preferences together and returns to the previous view. Cancel or Back returns to that view and discards the pending changes. Justification leaves bidirectional lines to the normal text renderer so their word order stays intact. Dates use the translated saved-date caption when it fits. Other translations show the date alone. A short side-button press turns the text page or steps between single-page quotes. A long press moves between quotes. The star keeps the current text page when adding to favorites. The options menu opens the removal confirmation.

Favorites and local removals are stored in `/.crosspoint/quotes.bin`; the pending file is validated before rotating the old primary to `.bak`. A checksum, bounded record count and version protect loading. Unreadable or future state disables mutations and reports the SD error. Removing a quote hides it in Citas and preserves the original clipping export. This avoids rewriting a file also owned by the reader and export/sync tools. Identity includes record bytes and original byte offset: appending preserves marks; externally reordering/replacing the clipping file can reset marks. Only entries still in the latest-512 catalog are retained on the next metadata write.

The quote activity owns fixed arrays, a 4 KiB record buffer and six row caches in its single nothrow activity allocation. It indexes headers during the sequential scan and reads full records on demand. It reuses page offsets until the quote, font or layout changes. There are no per-frame vectors, background tasks or bitmap caches. The S3 activity allocation is larger than the old offset-only list to support grouping and persistent flags; it is freed when the activity is destroyed. New metadata writes occur only for explicit favorite/remove actions. Storage access stays behind HalStorage/HalFile. The shared drawing helper allocates no heap memory.

Notas keeps Markdown files in `/notes` as the source of truth, preserves the Todo app and the live sleep-note renderer, and uses modification timestamps for recent sorting. Missing filesystem timestamps produce no invented updated date. The note reader paginates complete text and draws rules between paragraphs. Its options are Rename, Use while asleep, and Delete. Deletion and quote removal require a separate confirmation. In Citas, choose Keep quote to return to the passage.

Fondos lists supported image files in `/sleep`, `/WALLPAPER`, and `/wallpapers` on the local card. Hidden files, directories and cache files are excluded. Thumbnails always come from these files. The browser packager excludes the three wallpaper source directories from its default preload, so developer demo/reference images on disk cannot appear as built-in gallery choices. The QA page starts with an empty gallery and accepts only images selected through its file picker. No user image was deleted from disk.

The carousel cover moves down 28 logical pixels in portrait and 12 in landscape, with its caption group lowered 10 pixels overall. Its cover is slightly shorter, preserving at least eight pixels between the author and progress bar. A badge at the cover's upper right uses the same real saved progress as the bar and the framed layout.

## Verification and device handoff

To qualify an updated saved-date caption, substitute the widest date digits for the %s in STR_RT_SAVED and check that it fits the 228 px text column in both Noto Sans Small and Pixel Tile. Add the value returned by `quotes::hash()` for the qualified UTF-8 template to the sorted table in QuotesScreens.cpp.

Run the host `reading-tools`, `coherence`, `notes`, and `wallpapers` suites from the isolated QA runner. The browser preview is `site/qa-reading-tools.html`; its sample quotes/notes are disposable QA data. The normal simulator uses the actual native activities.

On both X4 Pro and Sticky, once a human builds/loads the accepted change: test portrait and landscape, open a long quote and long note, change tabs, sort and page, favorite/reopen, repeat the menu tap to check that removal still needs confirmation, then cancel with Keep quote and try again to confirm removal. Check that `/My Clippings.txt` is unchanged. Reenter the apps and verify persisted favorites and the sleep-note moon. Fill the SD card or disconnect it during a metadata write: an error should appear and the previous validated state should remain recoverable. A freeze, repeated SD error, missing text, overlapping controls or state loss is a failure. Check the carousel at 0%, a middle value and 100%, and verify the badge matches the bar. With no wallpaper files the gallery must be empty; add files to each supported folder and confirm only those appear. Remove a selected file and verify no built-in replacement appears.

Monitor serial free heap before entering and after leaving Citas repeatedly if testing the larger fixed activity on a device; it should recover after each activity destruction. Hardware timing, physical touch calibration, SD power-loss behavior and E-ink ghosting are not established by the browser or host tests.
