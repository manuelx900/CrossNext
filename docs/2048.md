# 2048

Open Games and select 2048 (the last installed game; it can be hidden with the folder gear). Resume opens the saved board. New Game asks for confirmation; How to Play uses three illustrated cards for directions, merging equal tiles and reaching 2048. The paused menu retains a board preview and score/best strip. New Game shows a checker/restart illustration and explains that the current board is replaced while the best score is kept. Swipe up/right/down/left on the board, tap the direction controls, or use logical direction buttons. Board swipes take precedence over swipe-back; the header Back arrow remains available. Global device gestures keep their existing ownership. The shared Back arrow/gesture opens the game menu, then returns to Games.

The board uses the shared pixel fonts, monochrome tiles and four-pixel outer frame. Matching tiles merge once per move and the merged value adds to the score. A valid move spawns a 2 (90%) or 4 (10%). No-op moves preserve the board and random state. Reaching 2048 allows continued play. No Moves Left means a new game is needed. The best score survives starting a new game.

Reaching 2048 for the first time in a game opens a victory screen. View board
continues the game; later merges do not repeat that notice. A board with no legal
moves opens a defeat screen, including when resuming a saved finished board.
Both screens offer New game, View board and Back to menu. Viewing a lost board
does not change it. A result saves the current board immediately.

State uses fixed arrays, no tile heap allocations and no animation buffer. Saves alternate between `/.crosspoint/2048-a.bin` and `2048-b.bin`, 80-byte versioned/checksummed slots. Dirty state saves on leaving, sleep and at most once per 30 seconds while playing. A failed save is shown; the other valid slot remains recoverable. Unknown future formats and two damaged saves are preserved without overwriting. Backups of these files can be restored with the device stopped.

Rules adapted from [Gabriele Cirulli’s original 2048](https://github.com/gabrielecirulli/2048), under the [MIT license](../src/apps_local/game2048/LICENSE-2048.txt). The game logic is rewritten for fixed embedded storage; no browser engine or network dependency is included.

Verify merges in all four directions, no double merge in one move, full-board game over, continued play after 2048, cancelled New Game and retained best score. Exit/reboot/sleep and resume the same board. Test both portrait and both landscape orientations, remapped direction buttons and Back. SD failure should display an error and preserve the last good slot. Hardware verification remains required.
