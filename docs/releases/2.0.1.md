# CrossNext 2.0.1

**Lighter Home icons · Quicker entry to Games, Apps and Settings**

This firmware patch for **Xteink X4 Pro** refines the Home menu and reduces the
work performed before common menus appear.

## What's changed

- **Lighter Home icons:** thinner, rounded silhouettes for a more consistent
  appearance across Framed, Carousel, Carousel2 and Bookshelf. Apps retains the
  reference design.
- **Games and Apps:** the menu appears before the navigation position is saved
  to the microSD. Changed navigation data is saved together after presentation,
  with an exit fallback and bounded retries if the card cannot be written.
- **Settings:** the category menu opens without first building every detailed
  settings list or discovering fonts and dictionaries. Reading resources are
  discovered when their settings are needed.
- **Go:** fixes an out-of-bounds diagonal-neighbor lookup when checking eyes.

The patch keeps the existing reading quality, book formats and save formats.

> [!TIP]
> **Already using 2.0.0? Update the firmware only.**
> Keep your installed Resources, Book Preparer 2.0.0, books and saved progress.
> This patch does not require a new resource pack or desktop installer.

## Install

1. Download `CrossNext-X4PRO-Firmware-v2.0.1.bin` and copy it to the microSD.
2. Open **Settings → Device → Update firmware**, select it and confirm.
3. Keep power stable until the update and restart finish.

For a first installation or an update from before 2.0.0, also install the
Resources from [release 2.0.0](https://github.com/manuelx900/CrossNext/releases/tag/2.0.0).
The compatible **Windows EXE and macOS DMG Book Preparer installers** are available
in that release too. See the [installation guide](https://github.com/manuelx900/CrossNext/blob/2.0.1/docs/install.md).

| Attachment | Purpose |
| --- | --- |
| `CrossNext-X4PRO-Firmware-v2.0.1.bin` | Application image for the microSD updater. |
| `CrossNext-X4PRO-Firmware-v2.0.1-factory.bin` | Combined image for factory USB installation at `0x0`. |
| `CrossNext-X4PRO-OTA.bin` | Application-only asset required by the online updater. |
| `CrossNext-X4PRO-Firmware-v2.0.1.zip` | Firmware images and installation instructions together. |
| `SHA256SUMS.txt` | Checksums for verifying the downloaded files. |

> [!IMPORTANT]
> The factory image belongs to the USB flashing route; select the application
> image in the microSD updater. The online updater uses **`CrossNext-X4PRO-OTA.bin`**.

These images target **X4 Pro (ESP32-S3)**. Follow the installation guide for other
starting firmware versions or partition layouts. Preserve `/.crosspoint/`, which
contains reading progress and app saves.
