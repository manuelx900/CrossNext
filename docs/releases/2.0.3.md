# CrossNext 2.0.3

## WORDS

- Unreadable vocabulary records are skipped without deleting saved words or blocking the entire app.
- A clearer recovery notice can be acknowledged and stays dismissed unless another unreadable record is found.
- Word lists and review sessions reuse prepared microSD views for navigation, keep the correct page count and avoid the history-loading interruption when changing pages.
- Saved words use an initial capital, the review answer highlights the word in bold, and the example text has cleaner spacing without the horizontal source divider.
- The Save word action is vertically centered.

## Navigation, clock and quick settings

- Apps and Games reuse menu metadata and coalesce redundant state writes to reduce repeated work when entering or returning to their menus.
- The Home games icon and quick-settings Wi-Fi icon are larger and better balanced.
- The Wi-Fi icon appears when connected and opens the existing Wi-Fi settings directly.
- The shared clock handling fixes the mismatch between the displayed and synchronized time across appearances, including Carousel.

## Keyboard and Wi-Fi password entry

- Text entry avoids an intermediate pressed-key refresh before inserting the character, while preserving language layouts, alternate characters and long-press actions.
- Show password also applies while editing, and returning from the keyboard keeps the chosen visibility.
- Cancelling password editing preserves the previous password and visibility, and a new password prompt starts hidden.

## Book Preparer for Windows and macOS

- A confirmation before preparation explains why one font and one size are recommended, shows the selected EPUB combinations and displays the available card space.
- Preparation checks free space before copying changed outputs and keeps a small reserve instead of intentionally filling the card.
- Clear CrossPoint cache can remove prepared pages by modification date or clear all recognized generated book caches while preserving books, settings, reading progress, saved words, statistics and game saves.
- Cache cleanup first shows the estimated space and file count, then requires acknowledging the warning before deletion is enabled.
- Date-based cleanup preserves older page files and shared book metadata; it does not restore overwritten versions, and removed caches will need preparation again.
- The Windows executable and both macOS disk images use the matching 2.0.3 preparation engine.

## Updating

Install the X4 Pro firmware and matching resources from this release, keeping your books and `/.crosspoint/` data.
The resource ZIP contains no root `images` folder or personal state.
Book Preparer is optional and runs on the computer; these storage controls do not add firmware RAM use or alter EPUB rendering quality.
The existing contribution from [@Snouzy](https://github.com/Snouzy) in [PR #31](https://github.com/manuelx900/CrossNext/pull/31) remains part of CrossNext; thank you for improving the display data transfer path.
