## What's new

- **Dictionary and translation in the reader.** Definitions and translations open over the current page. Tap outside the window or use the close button to return to reading. Use **Save** to add the word to Words. The matching resource pack ships with dictionary indexes for faster lookups.
- **Redesigned Quotes app.** Browse All, Books and Favorites in paginated lists with uniform cards. Long excerpts end with an ellipsis. Each quote has a single card for its source details, and you can choose the font, size and alignment of the passage.
- **Reader fixes.** Swiping back after following an EPUB link turns to the previous page. Quick Settings now follows the selected 12- or 24-hour clock format.
- **Focus and frontlight.** Focus returns to your last view after sleep. Set a schedule for frontlight brightness and warmth in Settings.
- **22 pt on compatible fonts.** The reader and Book Preparer for Windows and macOS support preparing EPUB layouts at 22 pt where the selected font supports it.
- **Faster text selection on supported X4 Pro panels.** Thanks to [@Snouzy](https://github.com/Snouzy) for the short-refresh waveform in [pull request #33](https://github.com/manuelx900/CrossNext/pull/33).

## Download and update

- **Xteink X4 Pro only.** Copy the application firmware to your microSD and select it under **Settings → System → Update firmware**. Use the factory image for USB installation.
- Install the matching CrossNext resource pack to get the prebuilt dictionary indexes. Back up your microSD first and keep your books, custom resources and hidden `/.crosspoint/` folder.
- **Book Preparer** is optional. Use the portable EXE on Windows, the arm64 DMG on Apple Silicon or the x64 DMG on Intel Macs.
