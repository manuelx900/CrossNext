# CrossNext 2.0.4

- Fixed the Bluetooth status banner in Quick Settings so it always opens Bluetooth settings when visible, including when no device is connected or paired, while reconnecting, and while Bluetooth is paused.
- Kept the Wi-Fi status shortcut working by routing both settings shortcuts through one existing action handler, without increasing the shared action table or adding persistent memory.
- Fixed incomplete wallpaper caches being treated as ready so all wallpapers are prepared before the app opens, with working progress feedback and without deleting the original images or changing image quality.
- Made Carousel and Carousel 2 cover-loading placeholders respect the Recent books setting: selecting one or two books now shows one or two provisional covers, and two available books no longer repeat the same neighboring cover.
- Removed bold styling from the Recent books on Home count dialog title.
- Reduced avoidable work when opening Settings, including Display, by collecting the retained options in one pass while preserving their order, values, and dictionary choices.
- Updated the Files and Games Home icons with the approved folder design and a compact controller silhouette, keeping the existing bitmap dimensions and runtime rendering path.
- Refreshed the coordinated Book Preparer packages to version 2.0.4 for Windows, Apple Silicon Mac, and Intel Mac; the EPUB preparation engine and cache formats remain compatible.

The resource pack includes the current languages and versioned PET and Reading Adventure content, without a root images folder or personal reader data.

The changes retain the existing EPUB rendering quality and radio policies; actual response time and dynamic memory use still depend on the device, book, and microSD card.
