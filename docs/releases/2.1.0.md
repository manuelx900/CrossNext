## BookOrbit on X4 Pro

Set up your server and account in **Settings → Connectivity → BookOrbit**. Browse and search your catalogue, choose where books are saved, and open an existing download directly from the catalogue.

- Enable automatic sync on sleep and on wake separately. Sleep sync can reconnect to a saved Wi-Fi network. On wake, the reader can pick up a newer position from the server when it is safe to apply.
- Use **Sync pending** for books with local changes. The **Reading** tab also shows the current book. Use **Recent** to sync a book individually. The batch summary lists which books were synced, skipped, or had errors.
- Use **Sync with BookOrbit** in the EPUB menu to resolve conflicting positions manually. In the toolbar layout, find it under **More**. BookOrbit matches the exact EPUB file when it is also available on your server.

BookOrbit syncs reading position and percentage. Reading statistics such as time, sessions and streaks stay on the device.

## Reading and apps

- Home remembers EPUBs without cover art and skips a second refresh when no thumbnail is available. Books with covers can still show them.
- The on-screen keyboard updates the affected areas during input. Bluetooth page turners can reconnect after a BookOrbit check on wake.
- The Apps menu and its visibility editor use larger, redrawn icons across all four appearances.
- The Reading Adventure shop shows items as you unlock them. PET has simpler Care and Health cards, and Rest shows how much energy your pet can recover.

## Install on Xteink X4 Pro

- **microSD update:** Use `CrossNext-X4PRO-Firmware-v2.1.0.bin` in **Settings → System → Update firmware**.
- **OTA:** Use **Settings → System → Check for Updates**. The attached `CrossNext-X4PRO-OTA.bin` is the application image used for this route.
- **USB factory installation:** On devices that support USB flashing, use `CrossNext-X4PRO-Firmware-v2.1.0-factory.bin` at `0x0`.
- **Resources:** Keep your existing 2.0.7 resource pack. For a first installation, use the attached `CrossNext-Resources.zip`. The optional Book Preparer installers are available with [2.0.7](https://github.com/manuelx900/CrossNext/releases/tag/2.0.7).

The release includes firmware license notices in `CrossNext-Licenses.zip`. [Source and license](https://github.com/manuelx900/CrossNext/tree/2.1.0).
