# CrossNext 2.0.0 — a faster reading workflow, a desktop preparer, and a larger adventure

CrossNext 2.0.0 is a major update from **1.4.0** for **Xteink X4 Pro**. It brings
reader and Library performance work, redesigned controls and artwork, more
complete language support, and a companion application for Windows and macOS.
**CrossNext 2.0.0 is based on [CrossPoint 2.0.0](https://github.com/crosspoint-reader/crosspoint-reader/releases/tag/2.0.0)** and retains its app/game foundation from [CrossPlay 1.14.2](https://github.com/ma-r-s/crossplay/releases/tag/v1.14.2). Thank you to their contributors.

## Reading and speed

- Select **New** or **Classic (1.4)** under Settings → Reading → EPUB engine.
  Compare them using the two original English-only EPUBs attached to this release.
- Reuse parsed chapter events, exact word measurements and valid page layouts
  when changing typography. Image decoding and cache writes use larger bounded
  batches and existing resource caches. These changes preserve the rendering
  algorithms and image settings; they do not make the physical e-ink refresh instantaneous.
- More responsive font, size, weight, indentation, line/paragraph spacing and
  alignment controls, with per-book profiles and clear general-default help.
- Consistent Contents and Font controls across the four appearances, including
  chapter counts and Regular/Bold previews. Improved image handling, book search,
  bookmarks, quotes and dictionary presentation are part of the coordinated update.
- Choose how to open book settings: bottom swipe, page-center tap, center-button
  hold, side-button hold, **bottom-edge tap**, or **top-edge tap**. Find the
  selector in **Settings → Controls → Buttons → Open book settings**. A top swipe
  still opens quick settings. Each selection chooses one opening method.

## Windows and macOS Book Preparer

The new **CrossNext Book Preparer 2.0.0** runs the real firmware preparation
pipeline on a computer. It prepares metadata, EPUB pagination, processed images
and the cover variants used by the home themes and Library. It also handles XTC/XTCH.

- **Windows x64:** `CrossNext-Book-Preparer-Windows-v2.0.0.exe` is portable.
- **Apple Silicon:** `CrossNext-Book-Preparer-macOS-arm64-v2.0.0.dmg`.
- **Intel Mac:** `CrossNext-Book-Preparer-macOS-x64-v2.0.0.dmg`.

Select the microSD root, check the detected reading engine/font/layout and choose
the combinations to prepare. Cancel retains completed work; compatible outputs
are reused on the next run. Books, settings, progress and app saves are preserved.
New font/size/layout combinations can still need preparation. Safely eject the card.
The applications are not notarized with an Apple Developer certificate; platform
security prompts may apply. DMGs are built on macOS and verified as disk images.

## Library and home

- Four appearances: Carousel, Framed, Carousel2 and Bookshelf, with shared icons,
  battery indicators, navigation and more consistent selection styles.
- Faster resource reuse when returning home and opening Recent/Collections.
  Cover loading displays the existing book placeholder, then the final cover;
  a title fallback is used for books without artwork. No extra blank/gray stage
  is deliberately added to list views.
- The loading notice can be enabled per home appearance. It defaults to on for
  Bookshelf and off for the other three. Without it, the cover is prepared before
  showing home. Its position adapts to the cover area, including Framed.
- Collections use a 3-column × 2-row portrait grid, book-count icons and an
  aligned edit control. Entry uses resident counts when available; filters whose
  totals require SD work wait for a real count instead of showing a guessed pager.
- Corrected return gestures from Collections, Filter and opened collections,
  plus the Carousel2 selection and skipped-item problems.

## PET and Reading Quest

- PET has revised Album statistics, larger reading-time artwork, consistent
  headers/back controls and improved translated layouts. The daily-prize counter
  text is removed from Play; its underlying daily reward rules remain.
- Reading Quest has a clearer hero menu: name and title above the full scene;
  tapping **Level** opens experience and equipment statistics over the menu.
- Larger hunt and equipment illustrations, improved insufficient-coins and
  completed-shop views, illustrated Saga pages and clearer reward navigation.
- Shop gates and prices progress through **level 150**. Outfit cards show power
  with a sword icon. Useful numeric effects remain, without repeated generic
  reading-benefit text or duplicate ownership labels.
- Hunts remain repeatable after completing the campaign/bestiary. Repeat wins
  give EXP and coins, while unique outfits, pets, scenes and decorations are
  obtained once. Victory counts appear in the selected Keepsake detail.
- Each campaign encounter and hunt attempt is individual: surplus session minutes
  are not banked for the next battle. Already active campaign/hunt goals can
  progress together. The final King of Oblivion requires twice the penultimate
  battle's scaled, rounded target with the same level/equipment.

## Wordle, keyboards and languages

- Wordle gains expanded multilingual word banks, consistent game keyboard
  styling, long-press alternatives and the standard erase icon. Supported word
  banks have different coverage; no finite dictionary can promise every real word.
- Ruled-out Wordle keys fade while remaining tappable, adapted from
  [PR #13](https://github.com/manuelx900/CrossNext/pull/13). Thank you,
  **[JankyChris / Christoph Jankowsky](https://github.com/JankyChris)**!
- Revised language layouts and a scrollable keyboard-layout selector, plus
  contextual translation and text-fit work across the reader, apps, games and web UI.
- Resources includes editable interface translation material and a CSV template.
  Correct wording using the documented language-pack tool; do not edit binary
  `.cplang` files in a text editor. The English keys and placeholders stay stable.

## Fonts and Resources: install the matching package

Extract **`CrossNext-Resources.zip` into the microSD root** and keep its licences.
The `apps`, `fonts`, `languages` and `dictionaries` folders belong at the root,
not inside an extra Resources directory. Do not replace or delete `/.crosspoint/`.

The full resident book-font selection has moved to SD resources to free firmware
flash. Install the supplied `/fonts` families, including Noto Serif and optional
Noto Sans, before selecting them in a book. **Small Noto Sans/Noto Serif interface
cuts remain in firmware**; the reading font and interface font are separate.
Ubuntu remains the resident reading fallback. A missing family is reported/falls
back without discarding the intended font selection. Resources also supplies
multilingual glyphs, keyboard/Wordle data, app artwork and licensed dictionaries.

## Install 2.0.0

1. Back up your microSD, including hidden `/.crosspoint/` data.
2. Install matching Resources and restart after updating their contents.
3. For a compatible installation, copy **`CrossNext-X4PRO-Firmware-v2.0.0.bin`**
   to the card and select it in Settings → Device → Update firmware.
4. `CrossNext-X4PRO-Firmware-v2.0.0-factory.bin` includes bootloader/partitions
   and is for USB at **0x0**, not the SD updater. Existing small application slots
   may need factory installation; an SD update cannot enlarge partitions.
5. `CrossNext-X4PRO-OTA.bin` is the matching raw application alias used by online
   updates. Check `SHA256SUMS.txt`. These images are for X4 Pro, not X4/X3.

Read the installation guide and the validation report included with the release
folder. Host/simulator checks do not establish physical wake, touch, power or
e-ink timing. Verify on your X4 Pro before publishing this prepared release.
