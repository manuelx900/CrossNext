# Reader text and page settings

While reading, swipe **up from the bottom edge**. EPUB and TXT (through the existing converter) open Text Settings. This is independent of the legacy reader-menu and touch page-turn preferences. On boards without a Home key it takes priority over the bottom-edge Home gesture only while the reader itself is active. Tapping the page center no longer opens a menu. With touch reader controls enabled, the lateral 15% edges go back (left) or forward (right), alongside swipes; the top and bottom 32 pixels retain edge-gesture ownership. Physical Confirm opens the same sheet; Back still exits. Middle-page vertical swipes do not open settings; coordinates follow the current orientation.

The panel overlays the bottom of the **current book page**. Its upper horizontal rule separates the controls from the real text left visible above; it has no full-screen title or replacement sample. Contents, Font, Layout and More are rectangular tabs in that order. Contents shows four chapters per portrait page (two in landscape), with previous/current-total/next controls. Chapter titles use the document-selector regular face at a fixed size, preserving their case, up to two lines, with a visible ellipsis when too long. Font keeps built-in/SD families, point size and regular/bold selection; tap Font, then its family row to open the paged list. The family-list header arrow returns to Font, while Back to reading closes the whole panel. Selecting the same family avoids redundant save/reflow. Layout has stepped line-spacing and margin bars, and Left, Centre and Justified alignment choices. Other style preferences remain in Settings > Reading. More offers search, state-aware Add/Remove bookmark, bookmarks and notes, page/percentage jump, book statistics and sync. Back to reading, Back, tapping the book above or swiping down closes the panel. Changes retain the existing content-offset reflow path.

XTC opens supported Layout, Contents (when chapters exist) and More controls over its image. XTCH grayscale pages offer Contents and More because their renderer has no status-bar overlay. Fixed-layout controls cover status-bar placement, percentage and refresh frequency, including Never. Dark mode is available in global Quick Settings. Enabling percentage while the bar is hidden places it at the bottom. Rotation fits the bitmap within the oriented safe area, using the same mapping for grayscale planes without another framebuffer.

In Contents, swipe left to show the next page of chapters or right to show the previous page. The visible page controls remain available. Swiping past the first or last page leaves the list in place. These gestures page the index without changing the current book page; tap a chapter to open it. EPUB/TXT and XTC/XTCH use the same directions in each screen orientation.

This tree has EPUB/TXT and XTC reader implementations, with no native PDF renderer. This change does not add PDF support. A PDF converted to a supported format receives controls for the resulting format.

LOCAL_SCOPE.md lists the gesture/presentation seams. ReaderToolbarUi owns the shared FreeInkUI sheet and fixed workspaces. The EPUB reader keeps its existing overlay refresh, optional B/W snapshot and repagination lifecycle. On a classic-menu configuration, opening this shortcut makes the existing optional snapshot path reachable: it can temporarily retain one page-sized B/W copy; allocation failure falls back to re-rendering. Changes discard stale snapshots before reflow; closing frees the overlay UI. A fixed 256-byte member caches the available uint8 point sizes from existing font metadata on entry/family change, with no per-paint size allocation. The swipe flow reuses the existing registry and sheet host and does not push a separate font activity. The full Text Settings screen remains available through Settings > Reader. SD font loading and overlay destruction run under the render lock. XTC allocates the same bounded UI host only while its panel is open, paints it on the current frame and redraws the image to dismiss; it adds no image snapshot. Its progress cache avoids rewriting the unchanged page on setting-only redraws. No worker/network task is added. All new system strings use English YAML and tr().

Device checks: open EPUB and TXT; exercise bottom swipes in all four orientations, all tabs, the family list, alignment and Back to reading. Verify the current paragraph remains nearby after reflow. Try SD fonts, missing-family fallback, long chapter names and long lists. Open XTC/XTCH, rotate via Quick Settings, dismiss and confirm all page edges remain visible. Test supported status/refresh options. Search a large single-spine book with an absent query, then cancel immediately; Back/Power polling should remain responsive between chunks. Repeat entering/exiting without choosing a result. Verify current-page bookmark Add/Remove copy. Watch for missing glyphs, stuck targets, heap loss or stack exhaustion. Hardware verification is pending. See [reader-controls.md](reader-controls.md) for resource ownership and bounded-search limitations.

Carousel 2 and Bookshelf show five reading-font families per page, using two columns in landscape so each choice retains its touch area. Other themes retain their existing family-list density. The installed reading families are independent of the interface font.

Bitter and Lexend Deca are supplied with all four styles as an OFL-licensed SD pack. See [interface layouts and fonts](interface-layouts.md) for installation, licensing and runtime checks.
